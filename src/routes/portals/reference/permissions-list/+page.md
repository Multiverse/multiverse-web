---
title: "Permissions List"
---

<code>multiverse.portal.access.\*</code> - Allows a player to use all portals.<br>
<code>multiverse.portal.access._(PORTALNAME)_</code> - Allows a player to use a specific portal.<br>
<code>[multiverse.portal.config](/portals/fundamentals/commands-usage/#Config-Command)</code> - Allows setting global MV-Portals config values.<br>
<code>[multiverse.portal.create](/portals/fundamentals/commands-usage/#Create-Portal-Command)</code> - Allows a player to create a portal.<br>
<code>[multiverse.portal.debug](/portals/fundamentals/commands-usage/#Debug-Command)</code> - Extra information about portal use is sent to console for error checking.<br>
<code>multiverse.portal.exempt.\*</code> - Allows a player to use all portals free of charge.<br>
<code>multiverse.portal.exempt._(PORTALNAME)_</code> - Allows a player to use a specific portal free of charge.<br>
<code>multiverse.portal.fill.\*</code> - Allows a player to fill all portals with lava/water.<br>
<code>multiverse.portal.fill._(PORTALNAME)_</code> - Allows a player to fill a specific portal with lava/water.<br>
<code>[multiverse.portal.givewand](/portals/fundamentals/commands-usage/#Wand-Command)</code> - Allows the player to receive the portal selection wand.<br>
<code>[multiverse.portal.info](/portals/fundamentals/commands-usage/#Info-Command)</code> - Allows viewing information about a portal.<br>
<code>[multiverse.portal.list](/portals/fundamentals/commands-usage/#List-Command)</code> - Allows listing all portals on the server.<br>
<code>[multiverse.portal.modify](/portals/fundamentals/commands-usage/#Modify-Portal-Command)</code> - Allows modifying portal properties.<br>
<code>[multiverse.portal.remove](/portals/fundamentals/commands-usage/#Remove-Portal-Command)</code> - Allows removing a portal.<br>
<code>[multiverse.portal.select](/portals/fundamentals/commands-usage/#Select-Command)</code> - Allows selecting a portal region.<br>
